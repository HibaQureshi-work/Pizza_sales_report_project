# Pizza_sales_report_project

-------------------------------------------------Pizza Sales Report Project----------------------------------------------------

This project provides a comprehensive sales analysis for a fictional pizza restaurant using Power BI for visualization, SQL for data querying, and Excel as the data source. It delivers insights into key performance metrics, sales trends, and product-level performance to support business decision-making.

1. Dashboard Overview

The Power BI dashboard presents the following analyses:

 Key Performance Indicators (KPIs):
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

 Trend Analysis:
- Daily Sales Trend (Total Orders by Day of the Week)
- Monthly Sales Trend (Total Orders by Month)

Category-Level Insights:
- Sales Distribution by Pizza Category
- Sales Distribution by Pizza Size

 Product Performance:
- Top 5 Best Selling Pizzas by Revenue, Quantity, and Orders
- Bottom 5 Pizzas by Revenue, Quantity, and Orders

2. Tools & Technologies

Tool/Tech 
| Power BI | Data visualization and dashboard creation |
| SQL Server | Data querying and transformations |
| Microsoft Excel | Data source (.xlsx) containing raw sales data |

3. SQL Queries Used

SQL queries were written to extract KPIs and generate data for charts. Key queries include:

- Revenue and order summaries
- Sales by day/month
- Percentage sales by pizza size and category
- Top and bottom performing pizzas

You can find the full list of queries in the file: [PIZZA SALES SQL QUERY.docx](./PIZZA%20SALES%20SQL%20QUERY.docx)

4. Project Files

| pizza_sales_excel_file.xlsx | Raw data used in Power BI |
| PIZZA SALES SQL QUERY.docx | SQL scripts used for insights |
| PIZZA SALES REPORT.pbix | Power BI report file |

5. How to Use
   
1. Open the .pbix file using Power BI Desktop.
2. Load the Excel file (pizza_sales_excel_file.xlsx) as the data source.
3. Review and edit SQL queries if needed to connect to your database.
4. Explore visualizations and insights on sales performance.

6. Insights Gained

- Peak sales occur during weekends.
- Medium-sized pizzas generate the most revenue.
- Certain pizza types consistently rank as top sellers, indicating customer preferences.
- Bottom performers highlight areas for promotional focus or product revision.
